# Tarea: Procedimiento básico de colaboración en GitHub

# Objetivo:

Aplicar un flujo simple de colaboración en GitHub: organizar trabajo con Issues, trabajar en una rama, solicitar revisión mediante Pull Request (PR) y cerrar el ciclo con Merge.

## Guia Rapida de Uso del repositorio
1. Clona el repositorio a tu maquina local usando GitHub Desktop.
2. Crea un branch para la tarea asignada ejemplo: feature/<nombre-de-branch>.
3. Abre un Pull Request solicitando revision antes de hacer Merge al main branch.
